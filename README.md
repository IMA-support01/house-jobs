# House Jobs

A kitchen tablet board for one house: small jobs for points, weekly zones that rotate, a captain, and a week sum-up that can go to the WhatsApp group.

Open https://ima-support01.github.io/house-jobs/ on the tablet and use Add to Home Screen.

Points are saved on the tablet only, in the browser. Nothing is sent anywhere. Use Settings, then Save a backup, now and then.
